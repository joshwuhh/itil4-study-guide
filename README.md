## 📖 What's Inside

The guide covers all 7 ITIL 4 Foundation Learning Outcomes (LOs), mapped directly to the official AXELOS candidate syllabus and textbook.

| Section | Coverage | Exam Marks |
|---|---|---|
| **LO 1** — Key Concepts | Service, Utility, Warranty, Value, Outputs, Outcomes, Roles, Service Relationships | ~5 |
| **LO 2** — Guiding Principles | All 7 principles with core ideas, mnemonics, interaction | ~6 |
| **LO 3** — Four Dimensions | Organizations & People, Info & Tech, Partners & Suppliers, Value Streams & Processes | ~2 |

| **LO 7** — 7 Practices (Deep) | Continual Improvement, Change Enablement, Incident, Problem, Service Request, Service Desk, SLM | ~17 |

## ✨ Features

### 📚 Study Content
- **Definitions** for every examinable term, word-for-word from the ITIL 4 textbook
- **Real-world example toggles** on every definition card — tap to reveal a practical scenario
- **Practice Q&A embedded in each section** — questions directly answerable from that section's content
- **1-week day-by-day study plan** mapped to mark weight (heaviest topics first)
- **Exam overview** — format, question types, pass mark, time allowed

### 🎯 Mock Exam
- **110-question pool** across all 7 LOs
- **40 questions drawn randomly** each attempt using stratified sampling (proportional to real exam mark weights)
- **Answer options shuffled** on every attempt — can't memorize position
- **Instant scored results** at the bottom of the exam with pass/fail verdict
- **LO breakdown** — color-coded score bars per learning outcome showing exactly where to focus
- **Attempt history** saved locally — tap any past attempt to expand the LO breakdown

### 📱 Mobile / iPhone
- Installable as a **home screen app** (PWA) — works fully offline after first load
- Slide-in **hamburger nav** with smooth scroll-to-section
- All tap targets meet Apple's 48px minimum
- Tables scroll horizontally on small screens
- Safe area support for notch and home indicator

## 📊 Exam at a Glance

| Item | Detail |
|---|---|
| Questions | 40 multiple choice |
| Pass mark | **26 / 40 (65%)** |
| Duration | 60 minutes (75 if non-native language) |
| Materials | Closed book — nothing allowed |
| Negative marking | **None** — always guess |
| Bloom's levels | Level 1 (recall) + Level 2 (comprehension) |

### Question Types
- **Standard** — one question, four options
- **Negative** — "Which is NOT…"
- **Missing word** — fill the blank from four options
- **List** — pick **two** correct statements from a list of four

## 🧠 7 Guiding Principles (Mnemonic: F-S-P-C-T-K-O)

| # | Principle | Key phrase |
|---|---|---|
| 1 | **F**ocus on value | "Why does this matter to the customer?" |
| 2 | **S**tart where you are | "What can we reuse?" |
| 3 | **P**rogress iteratively with feedback | "Work in small loops; learn and adjust." |
| 4 | **C**ollaborate and promote visibility | "Silos kill services." |
| 5 | **T**hink and work holistically | "The whole is more than its parts." |
| 6 | **K**eep it simple and practical | "If in doubt, leave it out." |
| 7 | **O**ptimize and automate | "Simplify before automating." |

## 🔑 Key Terms Cheat Sheet

| Term | One-line definition |
|---|---|
| **Service** | Enables value co-creation without the customer managing specific costs/risks |
| **Utility** | Fit for **purpose** — what the service does |
| **Warranty** | Fit for **use** — how the service performs |
| **Incident** | Unplanned interruption or quality reduction |
| **Problem** | Cause, or potential cause, of one or more incidents |
| **Known error** | Problem analysed but not yet resolved |
| **Workaround** | Reduces/eliminates impact when a full fix isn't yet available |
| **Change** | Addition, modification, or removal of anything that could affect services |
| **Event** | Any change of state significant for service management |
| **CI** | Any component that needs to be managed to deliver an IT service |
